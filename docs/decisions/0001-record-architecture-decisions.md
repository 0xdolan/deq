# 1. Record architecture decisions

- Status: accepted
- Date: 2026-11-08

## Context

Deq spans several languages, packages and formats. Decisions need to be traceable.

## Decision

Record significant decisions as ADRs in `docs/decisions/`, using a short [MADR](https://adr.github.io/madr/) layout: status, date, context, decision, consequences.

## Consequences

Each phase adds ADRs for the choices it makes. Superseded ADRs stay, marked "superseded by N".
